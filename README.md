# Artora Beauty Bar — Tenafly, NJ (`artorabeautybar.com`)

Luxury editorial website for **Artora Beauty Bar**, founded by Master Colorist & Stylist **Ayfer Deniz** (formerly of Ayfer Salon in Closter, NJ).

## Features
- **Airy Editorial Design**: Warm Alabaster (`#FAF8F5`), Travertine (`#F4EFE8`), Brushed Champagne Gold (`#C5A880`), and Deep Espresso (`#181715`).
- **Founder Spotlight**: Features Ayfer Deniz's biography, styling philosophy, interactive portrait gallery, and *People Magazine* (People's Choice Awards) press feature.
- **Curated Menu of Services**: Filterable service categories with direct booking links to [Vagaro](https://www.vagaro.com/artorabeautybar/services) plus an on-site Vagaro Booking Hub modal ready for inline widget embeds.
- **Transformation Lookbook & Motion Reels**: Filterable portfolio of retouched client portraits and muted looping H.264 `.mp4` hair transformation videos with a click-to-expand lightbox.
- **Visit Tenafly**: Live hours status indicator, embedded Google Map for **8 South Summit Street, Side Entrance, 2nd Floor, Tenafly, NJ 07670**, and direct contact links.

## Deployment
This is a zero-build static HTML5/CSS3/JS site. It can be deployed directly to **GitHub Pages**, **Netlify**, **Vercel**, or any web host by serving the root directory.
